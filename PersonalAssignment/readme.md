# Personal_Assignment: Student Restaurants Web Applicationä

## Overview
This is a web application called **Da Bear Eats**.

The application allows you to:
- Browse all student restaurants from both a scrollable list and an interactive map.
- Filter restaurants by various of options to quickly find what you're looking for.
- Register an account to create a personalized profile.
- Log in to your personal account to access your saved preferences.
- Set your own Avatar and Favorite restaurant.
- Modify your account settings.

  The app is built using HTML, CSS and JavaScript.
  It uses the [Metropolia Restaurant API](https://media2.edu.metropolia.fi/restaurant) (Requires Metropolia VPN)

- `css/` — Stylesheets:
  - `style-account-login.css` — Styling for login page.
  - `style-account-register.css` — Styling for register page.
  - `style-account-manager.css` — Styling for account settings page.
  - `style-global.css` — Global stylings such as Header and Footer.
  - `style-map.css` — Styling for map/filter page.
  - `styles.css` — Styling for Index page.
 
- `Images/` — Images displayed on application:
  - `banners/` — Styling for login page.
  - `icons/` — Styling for register page.
  - `logos/` — Styling for account settings page.
  - `other/` — Global stylings such as Header and Footer.
 
- `Scripts/` — Application Scripts:
  - `account.js` — Information and modifications on user account.
  - `auth-handler.js` — Token management and page access control.
  - `authorization.js` — Registration and login API calls.
  - `hamburger-menu.js` — Hamburger Menu logic which is located in navbar.
  - `script-accman.js` — Account modifications.
  - `script-login.js` — Login logic.
  - `script-register.js` — Register logic.
  - `script-map.js` — Displays Map view and Filter view and all the logic needed to implement those.
  - `script.js` — Scripts for main page.
  
- `index.html` — Main page.
- `map.html` — Map view / Filter view page.
- `account-register.html` — Register page.
- `account-login.html` — Login page.
- `account-manager.html` — Account settings page.
